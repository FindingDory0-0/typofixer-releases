# TypoFixer

자주 틀리는 단어를 등록해 두면 어떤 앱에서든 오타가 완성되는 순간 바로 고쳐 주는 macOS 메뉴바 앱입니다. (macOS 13 이상, Apple Silicon·Intel)

이 저장소는 **배포 전용**입니다. [Releases](https://github.com/FindingDory0-0/typofixer-releases/releases/latest)에서 최신 버전을 받으세요.


## 처음 설치하는 방법

1. 아래 **TypoFixer-버전.dmg**를 받아 열고, TypoFixer를 **응용 프로그램** 폴더로 끌어다 놓습니다.
2. 응용 프로그램에서 TypoFixer를 엽니다. "Apple은 이 앱에 악성 코드가 없음을 확인할 수 없습니다" 창이 뜨면 **[완료]**를 누릅니다.
3. **시스템 설정 › 개인정보 보호 및 보안**으로 가서 아래쪽 "TypoFixer은(는) … 차단되었습니다" 옆의 **[그래도 열기]**를 누르고 암호를 입력합니다.
4. 첫 실행 안내에 따라 **기기 제어 및 데이터 접근** 권한(macOS 26 이하는 **손쉬운 사용**)을 켭니다.

처음 한 번만 하면 됩니다. 이후 새 버전은 앱이 알려 주고, **[업데이트 설치]**를 누르면 권한이 그대로 유지된 채 바뀝니다.

> 업데이트 파일(`.zip`)과 `appcast.xml`은 앱이 자동 업데이트에 쓰는 파일이라 직접 받을 필요가 없습니다.
